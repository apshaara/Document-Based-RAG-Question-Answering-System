📄 Document-Based AI Question-Answering System using RAG

An AI-powered document question-answering system built using **n8n, OpenAI, and Pinecone** that enables users to interact with documents through natural-language conversations.

This project explores how Retrieval-Augmented Generation (RAG), AI Agents, document processing, and vector databases can work together to build intelligent knowledge-based applications.

🚀 Project Overview

The goal of this project is to build an AI-powered system that processes documents, retrieves relevant information, and generates contextual responses to user queries through a conversational interface.

 ⚙️ How the System Works

1. Document Ingestion and Processing
   - Google Drive integration to access documents.
   - Extract document content for further processing.

2. Text Chunking
   - Divide extracted text into smaller chunks.
   - Prepare content for efficient information retrieval.

3. Embedding Generation
   - Use OpenAI Embeddings to convert text into numerical vector representations.
   - Capture semantic meaning for similarity-based retrieval.

4. Vector Storage and Retrieval
   - Store embeddings in Pinecone Vector Database.
   - Retrieve relevant information based on user queries using semantic search.

5. AI Agent and RAG Workflow
   - Connect components through n8n.
   - Retrieve relevant context from the knowledge base.
   - Generate contextual answers using an AI Agent and an LLM.

6. Conversational AI Interface
   - Provide a chatbot interface.
   - Allow users to ask questions and interact with the system using natural language.
